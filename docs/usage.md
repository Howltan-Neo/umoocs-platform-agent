# 中文使用说明

## 安装与启动

先自行加入课程到“我的课程”。把README安装指令发给支持Agent Skills且能操作浏览器的智能体；安装目录为skills/umoocs-platform-agent，保持整个技能文件夹完整。已有同名技能只更新一份。

登录由你亲自完成，密码和验证码不要发给聊天或写入仓库。给出实际课程URL，明确允许智能体开始及提交哪些类别。智能体显示动态任务勾选面板：蓝色勾选交给AI，空框自己完成；作业与测验分开，期末/期中/结课独立，列表可以滚动，全选单元不会全选期末。

视频与目录状态修复默认勾选。AI视频弹题需要单独勾选；未授权时停留提示。视频速刷首次在每门课先试验并核验，不能仅按标题或另一门课的成绩启用。

按确认后，智能体自动保存本地配置。以后说“重开任务勾选面板”修改未开始项目；已经消耗的一次机会无法撤销。你也可说“只完成第2周的作业，测验由我自己做”，让智能体据实际目录更新选择。

## 需要你参与的情况

登录、验证码、工具缺少写入权限、未授权弹题或重要规则/材料缺失。普通情况不需要截图、复制源码或逐题操作。浏览器关闭会中断视频脚本；智能体停止则不再解题，技能不是无条件后台服务。

## 成绩与状态

填写读回验证的是输入是否一致，不是学术答案一定正确。普通作业允许重试时根据反馈修正；单次测验仅交一次。AI不保证满分，严格大小写、格式或题库固定答案可能造成失分。

成绩已批阅但目录未完成时，智能体先回原任务页检查同步；符合已授权单元修复条件才补平台正常通知。通知版本改变会停止，不重交卷、不改分数。

## 分享

分享仓库URL或dist生成的技能ZIP。不要分享runtime、浏览器配置、Cookie、题目答案或身份信息。其他智能体需具备相应浏览器能力，未经逐一验证的宿主不承诺完全无人干预。
