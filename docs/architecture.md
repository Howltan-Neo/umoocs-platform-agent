# 适配机制

课程URL → 当前账号目录 → 类型/状态/分组清单 → 勾选分工 → 每次操作前范围校验 → 原任务iframe → 正常播放/正常填写提交 → 批阅与服务器目录核验。

脚本不调用交卷API、不制造观看记录，也不直接改服务器学习状态。通知恢复仅调用当前平台原有完成事件模块，并以真实批阅结果与明确授权为前提。

视频脚本跨域握手校验origin、source、taskId，顶层只允许当前账号目录中的选中视频。播放位置和倍速作用于原HTMLVideoElement，结束后目录核验决定是否切换。弹题留在播放器中，由智能体正常答复或交给用户。

适配层：catalog.js识别标准课程；task-picker.js生成动态分工；task-scope.js校验指纹及任务；assessment-dom.js控制可识别字段；video-popup.js控制标准可见单选弹题；completion-notification.js按版本恢复漏通知。

标准平台通用，不等于所有课程自动兼容。新图标、播放器、题型、上传、富文本、音频以及通知版本需要独立检查或新增适配器。公共代码不绑定账号、课号、单元数或题库。
