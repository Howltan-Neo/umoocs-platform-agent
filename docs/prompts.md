# 可直接复制的 Prompt

按顺序使用“安装”和“启动”两段。启动前将 `[课程链接]` 替换为“我的课程”中实际打开的课程网址。其余文字可以原样复制；任务范围在勾选面板中选择，无须编辑 JSON。

## 1. 安装（首次使用）

```text
请从 https://github.com/Howltan-Neo/umoocs-platform-agent 安装
skills/umoocs-platform-agent 这个技能，保留整个技能文件夹。
使用你所在环境的技能安装功能，读取 SKILL.md 和必要参考文件。
检查浏览器操作、文件读写、页面脚本写入和持续执行能力。
优先使用允许的 DOM 工具；不支持时使用正常界面操作。
请自主完成安装和环境检查，告诉我是否需要重新打开应用。
不要安装两份同名技能，也不要沿用其他账号的授权或登录配置。
```

## 2. 启动、勾选与一次授权

```text
使用 $umoocs-platform-agent 处理这门课程：[课程链接]
先打开登录页面让我亲自验证，再读取真实目录并显示任务勾选面板。
我会勾选交给 AI 的作业、测验、期末考及视频功能，未勾选由我自己完成。
不要替我点击“确认任务分工”。

我授权你正常开始并提交我确认交给 AI 的项目。
先核对规则、尝试次数、计时和完成条件；无法查明机会数时先跳过并汇总。
普通作业先试运行一份；操作与实际结果核验成功后，我预先授权继续所选普通作业。
只对明确允许重复尝试的作业根据批阅反馈修正，最多再尝试两次。
一次机会的测试独立解答两遍，比较分歧并逐题复核，填入后读回，再提交一次。
提交结果不明只检查状态，不重复提交；已提交的单次测试不重做。
期末、期中和结课测验只有我独立勾选时才包含。

视频先在这门课的一个所选样本测试：拖动进度条到结束前3秒，
从最后3秒正常播放至结束，确认服务器目录完成后才用于其他所选视频。
若不可定位或目录不认可，改为16倍速从头完整播放，再失败用1倍速完整播放，
仍未确认则停止提示。不伪造记录，不绕过弹题或课程要求。
优先静音和原生最低可用画质；稳定后交给脚本，减少反复监测。
播放器弹题是否交给 AI，以我的独立勾选为准；不关闭或跳过未答弹题。

若我勾选状态修复，授权你仅对真实已提交、批阅满足条件的所选单元项目，
在匹配的平台通知模块版本下恢复原有完成通知并再次核验目录。
不改分数、不重交卷；该修复不用于期末、期中或结课测验。

尽量自主完成定位、适配、解题与调试，不反复询问已有授权。
只在需要登录验证、缺少权限、重要规则或材料缺失时提醒我。
保存简短进度；结束后清理临时题目答案、登录测试配置和无用截图，
保留必要技能与匿名结果，并汇总完成、未完成和异常项目。
```

## 3. 中断后继续

```text
使用 $umoocs-platform-agent，读取本账号上次的分工和简短进度，
核对课程实时目录与已提交结果，继续此前已授权的未完成任务。
跳过已完成项目，不重新开始或提交已交卷的一次性测试。
若账号或目录已改变，先重新核对分工，不沿用另一账号的授权。
```

## 4. 重新选择任务

```text
重新打开任务勾选面板，让我修改尚未开始的任务。
在我确认前暂停开始新的作业或测验；先说明当前是否有已开始且计时的试卷。
```

也可用自然语言修改未开始项目，例如：

```text
仅第2周和第4周普通作业交给 AI，其余作业自己完成。
单元测验全部自己完成，期末考自己完成。
视频仍按此前授权继续。请按实际目录核对并保存这次分工。
```

## 5. 切换账号或课程

```text
我要使用另一个账号或另一门课：[新课程链接]
请建立独立运行配置，打开页面让我亲自登录，重新读取目录并显示勾选面板。
不要继承旧账号的任务选择、视频完成验证或一次性测试记录。
待我确认新的分工后，再按本次明确授权开始。
```

## 6. 只检查提交后未显示完成的项目

```text
使用 $umoocs-platform-agent，仅检查本课程已经提交但目录未完成的单元项目。
先核验实际批阅和完成条件，不再次填写或提交试卷。
我授权在结果满足技能规定条件、账号与模块版本匹配时，
恢复平台原有单元完成通知，每项最多一次，再核验服务器目录。
期末、期中、结课测验不使用该修复；不符合条件的项目记录为异常。
```

## 7. 停止

```text
停止开始新的作业和测验，暂停视频串播，保存简短进度。
如果正在计时的试卷尚未提交，请先告诉我当前状态和剩余时间，等待我决定。
```

授权不会提高答案正确率，也不能恢复已消耗的一次机会。可按你的需求删改启动指令中的授权范围；选择面板与实际授权都必须吻合。
