## 调试修复

1. 代码生成中的JS replacement字符串含$与反引号导致替换语义错误；改用返回字面值的替换函数，并加语法检查。
2. 任务页没有完整账号导航导致误停；账号验证改为从服务器课程目录识别，并在握手前核验。
3. videoStatus在没有面板的页面等待超时；先检查元素数量，避免无谓30秒等待。
4. 跳到末尾触发叠加弹题；用命中测试识别最上层可见题，只通过正常选择、确认及完成按钮处理。
5. 限定视频样本后“全部视频完成”表述不准确；改为“本次选择的视频已完成”。

## 预览中文编码修复

模拟页面此前没有声明字符编码，浏览器按错误编码解读中文；这使课程标题及章节名乱码并传入面板。已同时增加 HTML 的 UTF-8 声明和响应 Content-Type 的 charset=utf-8，回归测试核验 document.characterSet、中文标题、个人主页和目录章节文本。重新生成 PNG 后实际打开检查，确认中文正常；不把代码断言通过替代视觉复查。
