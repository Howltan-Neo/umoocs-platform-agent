# UMOOCs 平台学习智能体

读取当前用户指令和精简进度，沿用同账号已有明确授权。使用宿主允许的浏览器能力；只有脚本写入权限才执行DOM助手，不把本包当作绕过工具权限的途径。用户亲自登录和完成验证码。详细参数按需读 [运行协议](references/runtime.md)。

## 识别与分工

1. 确认账号、已选课状态和真实课程链接。用scripts/catalog.js读取当前服务器目录，得到课程、真实任务ID、类型、状态和章节分组。无数字ID推算；标题Test不等于试卷。未知图标/状态或异常链接停止该项。
2. 首次启动用scripts/task-picker.js在任务开始前显示勾选面板，传入实际manifest。未选作业、测验、期末考均为manual；视频及单元状态修复默认勾选，可取消，AI视频弹题默认不选。同账号已有选择可预填；新账号重新确认，不能沿用另一账号选择。
3. 等用户自行确认，以action:read取回scope并写到本地。明确开始/提交授权与选择是两件事：已有用户授权时继续，不逐份重问；没有授权时一次问清。每次开始和提交前运行scripts/task-scope.js；manual不进入答题，目录变动则重新核对清单与分工。未知或未识别项目不自动放进AI范围。

## 视频

读取 [视频协议](references/video.md)。用当前目录建立选中视频白名单与账号绑定配置，默认未配置不运行。只保留一个有效串播页。标准适配器assets/umoocs-video.user.js只负责真实媒体操作及目录核验；不操作试卷或发送伪造观看记录。

新课程先读取课时完成条件，核验播放器、正常播放和速度实际值。用户授权跳转测试时，只对选中样本拖动进度条到结束前3秒，从最后3秒播放至结束，并确认服务器目录。通过后标记该课程seekVerified；不能由另一门课的成功推断。失败用16×从头完整播放，再失败1×完整播放；原速仍未确认则记异常。不能把跳转称作完整观看，不能绕过课程弹题或进度要求。

优先静音、原生最低可用画质；支持方式、倍速、醒目暂停串播及拖动面板。当前任务页可能没有账号导航，账号校验在服务器课程目录中完成，握手前验证视频类型、链接、白名单及状态。不同播放器不盲目注入，先检查再适配。

播放器弹题暂停是正常交互。已获AI弹题授权时用scripts/video-popup.js读取当前最上层可见题目，独立解答、选中读回、正常确认、核验反馈、按完成按钮关闭，随后恢复媒体。未知题型转宿主UI，不能跳过弹题或只删除弹窗。未授权时提示等待。该助手当前验证的是标准SDK单选弹题，不能声称支持所有弹题。

## 作业与测验

1. 始终在原任务show页的活动iframe开始、填写和提交，保留父子页完成通知。观察实际开始链接，不推算lesson或试卷ID。
2. 开始前读规则：机会数、计时、截止时间、计分与及格线、是否已提交。不要把未显示计时称作不限时。未知机会数先查，无法查明则说明；没有消耗未知机会的明确授权时停止。
3. 用scripts/assessment-dom.js或宿主允许的工具一次提取题目、完整材料、选项、稳定ID及字段。材料可能在第一题之前；保留材料与小题对应关系。不采用隐藏答案、其他账号题库或未核验缓存答案。题型不支持时先适配；图片、音频或教材未读取不能声称已解答。
4. 普通作业按独立解答、完整填入及读回、正常提交、反馈修正流程执行；只在平台确实允许重复且用户允许时重试，默认最多两次修正，仍有错误则记异常。不要因只读回成功就称答案正确。
5. 一次性测试独立解答两遍，比较分歧，重点复核否定词、材料依据、空格边界、时态、大小写和严格格式；随后验证每个字段及未答数量。重要歧义未解决时说明，不能承诺满分。只提交一次。把attempt状态在点击前记录为submitting，结果不确定只查状态，不重复点击或重开尝试；重启会话读取此记录。
6. 核验实际提交时间、批阅状态、成绩、错题、未答数及服务器目录。essay待人工批阅等场景如实记录pending，不能自动称全对或完成。已提交一次性项目不重做。

## 状态同步与收尾

核验批阅后同时读取服务器目录。已完成不补通知。已授权且确认真实结果满足条件时，可用scripts/completion-notification.js恢复标准平台的原有单元完成通知，再核验目录；匹配网页及模块版本，每项最多一次。当前策略为全对普通作业、界面明确通过的单元测验，期末/期中/结课不使用该适配器。它不重新交卷、不改答案分数、不直接写进度接口；版本或身份不匹配记异常。不同版本先调查，不能无条件套用。

复用一个浏览器会话，独立播放器与答题页，有计时的试卷只开一份。精简记录账号代号、课程URL、任务ID、规则、真实结果、异常和下一步；登录数据及完整题目答案不进入共享源码。稳定串播交给浏览器脚本，避免反复检查。智能体结束后不会继续推理答题，只有用户要求后续调度时才使用宿主自动化。

完成后汇总实际结果，按用户要求清理临时题目、答案、浏览器测试配置及截图。清理前停止相关进程，验证绝对路径在指定任务目录内；保留技能、说明、测试代码及匿名结果。发布只包含源文件及匿名证据，不上传runtime目录。
